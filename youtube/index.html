Connexion YouTube — Hadith Daily

1. Collez l'ID client OAuth de votre projet Google (Google Cloud → API et services → Identifiants). Il se termine par .apps.googleusercontent.com.

Chaîne :

L'ID client n'est pas secret. Ne collez jamais ici le code secret du client. Si Google affiche « Google n'a pas validé cette application », cliquez sur Paramètres avancés, puis sur Accéder à Hadith Daily : c'est votre propre application.
